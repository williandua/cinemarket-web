# CineMarket — site public

Pages publiques du jeu **CineMarket** (app iPhone) : page d'accueil, politique de confidentialité,
conditions d'utilisation. Publiées par GitHub Pages sur https://williandua.github.io/cinemarket-web/

- `index.html` — page d'accueil, gère aussi les liens d'invitation de coproduction (`?invite=CODE`)
- `privacy.html` — politique de confidentialité (URL déclarée dans App Store Connect)
- `terms.html` — conditions d'utilisation (EULA lié depuis le paywall de l'app)

Le code de l'app vit dans un dépôt privé. Ne rien ajouter ici qui ne soit destiné au public.
